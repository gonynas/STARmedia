# 구글 드라이브 연결 준비 (한 번만 · 무료 · 10분쯤)

견적서 발행기가 사용자님 구글 드라이브에 자료를 저장하고 PC ↔ 휴대폰 자료를 맞추려면,
구글에 "이 프로그램이 드라이브를 써도 돼요"라고 등록하는 **열쇠 번호(클라이언트 ID)** 가 하나 필요해요.
아래 순서대로 만든 뒤 **클라이언트 ID**(…apps.googleusercontent.com 로 끝나는 글자)를 AI에게 알려 주세요. 프로그램에 넣어 드려요.

> 비유: 드라이브는 사용자님 집 창고, 클라이언트 ID는 "이 심부름꾼(프로그램)은 창고의 견적서 칸만 열 수 있어요"라고 적은 출입증이에요.
> 이 출입증으로는 **프로그램이 직접 만든 폴더 · 파일만** 볼 수 있어요(권한 `drive.file`). 다른 드라이브 파일은 볼 수 없어요.

---

## 1. 프로젝트 만들기
1. PC 크롬에서 **https://console.cloud.google.com** 에 사용자님 구글 계정으로 들어가요.
2. 위쪽 **프로젝트 선택 → 새 프로젝트**를 눌러요.
3. 프로젝트 이름: `starmedia-quote` (아무 이름이나 괜찮아요) → **만들기**.

## 2. 구글 드라이브 기능 켜기
1. 왼쪽 메뉴 **API 및 서비스 → 라이브러리**.
2. 검색창에 `Google Drive API` → 눌러서 **사용**.

## 3. 동의 화면 만들기 (로그인할 때 나오는 안내)
1. **API 및 서비스 → OAuth 동의 화면**(또는 「Google 인증 플랫폼」) → **시작하기**.
2. 앱 이름: `스타미디어 견적서 발행기`, 사용자 지원 이메일: 사용자님 이메일.
3. 대상(사용자 유형): **외부**.
4. 연락처 이메일: 사용자님 이메일 → **만들기**.
5. **데이터 액세스(범위)** → **범위 추가** → `.../auth/drive.file` 하나만 체크 → 저장.
6. **대상** 화면에서 **앱 게시(프로덕션으로 푸시)** 를 눌러 「프로덕션」으로 바꿔요.
   - 「테스트」 상태로 두면 7일마다 다시 로그인해야 해요.
   - `drive.file` 권한만 쓰기 때문에 구글 심사 없이 바로 쓸 수 있어요. 처음 로그인할 때 "확인되지 않은 앱" 안내가 나오면 **고급 → (앱 이름)으로 이동**을 누르면 돼요.

## 4. 클라이언트 ID 만들기
1. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**.
2. 애플리케이션 유형: **웹 애플리케이션**, 이름: `견적서 발행기`.
3. **승인된 자바스크립트 원본**에 두 줄을 넣어요.
   - `https://gonynas.github.io`
   - `http://localhost:8080` (PC에서 시험할 때용, 없어도 돼요)
4. **승인된 리디렉션 URI**는 비워 둬요.
5. **만들기** → 나오는 **클라이언트 ID**를 복사해요. (클라이언트 보안 비밀번호는 쓰지 않아요. 누구에게도 알려 주지 마세요)

## 5. AI에게 알려 주기
> 구글 클라이언트 ID 는 `1234-abcd.apps.googleusercontent.com` 이야. 견적서 발행기에 넣고 깃허브에 올려줘.

이 ID는 비밀번호가 아니에요(웹 프로그램에는 원래 공개돼요). 위 4-3에 적은 주소에서만 로그인이 돼서 다른 곳에서는 쓸 수 없어요.

---

## 연결한 뒤 쓰는 법
- **PC**: 처음 열면 나오는 **처음 설정 ① 구글 드라이브 연결** → 구글 계정 고르기 → 허용. (드라이브에 예전 설정이 있으면 나머지 설정은 건너뛰어요)
  드라이브에 `01_견적서 발행기` 폴더가 생기고(백업은 그 안 `백업` 폴더), 자료와 하루 한 번 백업(최근 10개)이 쌓여요.
- **휴대폰**: 주소를 열면 첫 화면의 **구글 드라이브에서 불러오기** → **같은 구글 계정** → 바로 문서 발행.
- 그 뒤로는 입력하면 몇 초 뒤, 그리고 화면이 켜져 있으면 20초마다 저절로 맞춰져요. 구글은 1시간쯤마다 다시 확인해요 — 화면을 누르면 저절로 다시 연결하고, 안 되면 **「연결」** 팝업이 나와요.
