# 스타미디어 견적서 발행기 (첫 완성본 v1.0.0)

견적서 · 거래명세서 · 납품ㆍ청구서 · 영수증을 만들고, 행사 · 입금 · 장비 · 매출을 관리하는 프로그램입니다.
인터넷 주소로 열어 쓰고, 자료는 **쓰는 기기(와 고른 PC 폴더)에만** 저장됩니다.

## 쓰는 법
**실행 주소: https://gonynas.github.io/STARmedia/Invoice/dist/** (PC · 휴대폰 · 태블릿 모두 같은 주소)

1. 주소를 열고 「처음 시작하기」 → 내 정보 넣기 → (PC라면) PC 폴더 정하기.
2. 휴대폰 · 태블릿은 공유 버튼 → 「홈 화면에 추가」로 앱처럼 설치할 수 있어요.
3. 저장 버튼은 없어요. 입력하면 저절로 저장돼요.

## 문제가 생기면
1. **설정 · 백업 → 문제 기록**으로 가요.
2. 「무엇을 하다가 어떻게 됐나요?」에 한 줄 적고 **「AI에게 보낼 내용 복사」**를 눌러요.
3. Claude 또는 ChatGPT(Codex) 대화창에 붙여 넣고 이렇게 말해요:
   > 이 문제를 고쳐 줘. 프로그램 폴더는 app/ 이고, 먼저 AGENTS.md 를 읽어 줘.

복사한 글에는 거래처 이름 · 금액 같은 자료가 들어 있지 않아요.

## 기능을 더하고 싶으면
AI에게 이렇게 말해요:
> app/AGENTS.md 를 먼저 읽고, ○○ 기능을 더해 줘. 자료가 지워지지 않게 해 주고, 다 되면 npm run build 로 확인해 줘.

## 자료 지키기
- 설정 · 백업에서 **PC 폴더**를 연결해 두면 폴더에도 저절로 저장되고 백업도 쌓여요.
- 「자료 파일 내려받기」로 파일 하나에 모든 자료를 담아 둘 수 있어요(다른 기기에서 「자료 파일 불러오기」).
- 브라우저의 「인터넷 사용 기록 삭제」를 하면 이 기기 저장분은 지워질 수 있어요. PC 폴더나 자료 파일이 있으면 다시 불러올 수 있어요.

## 만드는 사람(AI)을 위한 명령
- `npm test` — 계산 규칙 시험
- `npm run build` — 시험 + `dist/` 만들기 (이 폴더를 웹에 그대로 올림)
